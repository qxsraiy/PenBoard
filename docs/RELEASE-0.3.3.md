# PenBoard 0.3.3

Windows x64 / ARM64 触控笔手写工具。

## 本版修复

- 移除原生覆盖层每次 `WM_MOUSEMOVE` 的同步文件日志；
- 移除每次绘制工具栏时的同步日志；
- 降低书写时磁盘 I/O 和 UI 延迟；
- 保留候选字点击、批注 PNG/PDF 保存、C# 托盘启动；
- x64 / ARM64 安装包和便携版。

## 已知限制

- 原生覆盖层 + C# 托盘合计内存约 100MB；
- ARM64 原生 exe 已打包，但本机只验证了 x64；
- 候选点击和批注按钮还没有自动化回归测试。
