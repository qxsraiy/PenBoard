# PenBoard 0.3.6

Windows x64 / ARM64 触控笔手写工具。

## 本版修复

- 恢复旧版顶栏/底栏结构：
  - 顶部居中模式栏：输入模式 / 批注模式；
  - 底部工具栏：笔、涂抹擦、整笔擦、黑/红/蓝、细/中/粗、切换模式、中英、退格、撤销、清空、关闭；
  - 批注模式显示存 PNG / 存 PDF；
  - 选中工具/颜色/粗细/语言使用高亮边框；
  - 工具栏位置改为底部 72px，候选栏位于工具栏上方。
- 批注保存不再包含 PenBoard 控件：
  - 启动原生覆盖层前隐藏悬浮按钮；
  - 原生截屏前等待 250ms；
  - 保存时隐藏顶栏、底栏、候选栏。
- 自动识别延迟从 900ms 改为 1600ms；
- 落笔时取消上一次识别定时器，避免停顿一下就被填充；
- 笔迹异常长线：
  - 忽略超出屏幕范围的点；
  - 相邻点距离超过 250px 时丢弃，避免瞬移长线。
- 擦除：
  - 涂抹擦删除局部笔迹点；
  - 整笔擦删除整条笔迹。
- 保留 ARM64 `WM_POINTER*` 按钮和识别修复。

## 已知限制

- 原生 UI 是按旧 WPF 布局重绘，不是逐像素完全一致；
- 仍没有候选/按钮自动化回归测试。
