# PenBoard 0.3.8

Windows x64 / ARM64 触控笔手写工具。

## 本版重点

- 继续使用原生 DirectComposition 覆盖层，但 UI 按旧 WPF 界面逐项复刻：
  - 顶部模式栏：y=16，高 36，圆角 10，背景 #CC141414，边框 #33FFFFFF；
  - 底部工具栏：底边距 72，按钮 y=968、高 33；
  - 按钮位置按旧 WPF UIA 实测坐标绘制：
    - 笔、涂抹擦、整笔擦；
    - 黑/红/蓝 30×30 圆形色块；
    - 细 37、中 39、粗 37；
    - 切换批注 78、语言 52、退格/撤销/清空/关闭 50；
  - 普通按钮 #26FFFFFF 背景、#40FFFFFF 边框、圆角 7；
  - 选中工具/粗细 #2D7DFF 高亮、白色 2px 边框；
  - 颜色选中白色圆环；
  - 语言中文红、English 蓝。
- 批注保存只渲染背景 + 笔迹，不绘制顶栏、底栏、候选栏。
- 批注打开前隐藏悬浮按钮并等待 250ms 再截屏。
- 识别延迟 1600ms；候选自动输入 2000ms。
- 打开后 350ms 内忽略笔迹。
- 相邻点距离超过 250px 的异常长线丢弃。
- 涂抹擦/整笔擦已实现。

## 已知

- 字体渲染与 WPF 仍有细微差异；
- 原生 UI 没有 WPF 的鼠标悬停动画。
