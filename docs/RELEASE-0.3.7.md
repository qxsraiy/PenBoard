# PenBoard 0.3.7

Windows x64 / ARM64 触控笔手写工具。

## 本版重点

- 撤回原生重绘 UI，恢复重构前的 WPF 覆盖层：
  - 顶栏、底栏位置和尺寸；
  - 笔、涂抹擦、整笔擦；
  - 黑/红/蓝；
  - 细/中/粗；
  - 切换批注/切换输入；
  - 中/English；
  - 退格、撤销、清空、保存、关闭；
  - 原有选中高亮逻辑。
- 批注保存继续使用原 WPF 导出器：
  - 只导出屏幕截图 + 笔迹；
  - 不包含工具栏、顶栏、候选栏。
- 批注打开前等待悬浮按钮隐藏后再截屏。
- 自动识别延迟改为 1600ms，候选自动输入延迟 2000ms。
- 打开覆盖层后的 350ms 内忽略笔迹，避免打开动作被当成第一笔。
- 单条笔迹相邻点距离超过 250 DIP 时丢弃，避免异常长线。

## 说明

- 本版优先恢复原样式和交互，不再使用原生重绘 UI；
- 内存会回到 WPF 覆盖层的水平；
- 原生 `PenBoard.DcompOverlay.exe` 仍随包保留，但默认不启动。
