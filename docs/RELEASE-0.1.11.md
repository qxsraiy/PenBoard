# PenBoard 0.1.11

Windows ARM64 触控笔全屏手写 / 屏幕批注工具。

## 本版修复

- **模式切换合并**：底栏只保留一个“切换输入/切换批注”按钮，位置在“细/中/粗”右侧；输入为蓝色、批注为红色，无输入光标时灰色禁用并提示“未检测到输入框”。
- **保存不退出**：保存 PNG/PDF 后覆盖层保持打开；只有“关闭 → 保存并关闭 → 选择格式”才关闭。
- **弹框空白**：保存/关闭弹框宽度按内容收缩，不再右侧大量空白。
- **更新进度**：检查更新下载时显示进度条和 MB 进度。
- **自动化**：
  - 所有鼠标左键点击都会触发输入框探测，不再依赖触控笔 `extraInfo`；
  - 保留 UI 焦点变化检测作为第二重兜底；
  - 打开前后强制隐藏系统手写板。
- **遮挡问题**：覆盖层每 800ms 重新置顶并隐藏系统手写板，避免虚拟键盘/状态栏遮住底栏。
- **单安装**：MSI 稳定 UpgradeCode + MajorUpgrade，`AllowSameVersionUpgrades=no`；0.1.11 独立发布，不覆盖旧版。

## 安装

运行 `PenBoard-0.1.11-arm64.msi`，首屏选择语言。per-user 安装，无需管理员。
